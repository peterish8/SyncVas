# 27 — Open Source and License Notices

## Product policy

Normal teacher/student UI should use our own product branding. Do not add “Powered by Excalidraw” to the classroom canvas unless desired for marketing/community reasons.

## Excalidraw

The upstream Excalidraw repository is MIT licensed. MIT permits use, modification, distribution, sublicensing and sale subject to retaining the copyright and permission notice in copies/substantial portions.

Implementation requirement:
- retain the upstream MIT notice in a third-party notices file / Open Source Licenses screen and relevant distributed copy
- do not imply official endorsement

## Socket.IO

Verify the installed package license at build time and retain required notices. Current upstream is distributed as open source and is appropriate for commercial use; the project pack assumes the MIT-licensed Socket.IO line.

## Process

Before production release generate/check a dependency license inventory. Flag GPL/AGPL or source-available dependencies for explicit review before adoption.

This document is engineering guidance, not legal advice.
