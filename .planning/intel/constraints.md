# Constraints (from ingest)

- Solo developer MVP — boring architecture over cleverness
- TypeScript strict; validated Convex args; ownership checks
- No unindexed full-table scans on production paths
- Versioned Socket.IO events; no secret/doubt-text logging
- Permission tests before polish
- If implementation conflicts with MVP docs, stop and report
- Classroom UI is canvas-first and high contrast; use the warm-neutral design system and only contained, accessible color-field accents
- Interactive chrome must follow Tactile UI System physics on Syncvas tokens: no hover scale, no glass/glow, raised buttons press 2px and lose bottom edge, inputs are inset with lime focus rings
- A P0 final board save must be complete and accepted in one teacher plus two student tabs before P1 work starts
